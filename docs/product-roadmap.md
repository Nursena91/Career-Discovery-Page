# Product Roadmap

## Phase 0: Product framing and validation

- hedef kullanıcıların netleşmesi
- kaynak listesi ve erişim durumu
- legal/ethical control
- MVP tanımı

## Phase 1: MVP foundation

- repository setup
- backend base app
- source adapter basics
- data schema
- scraping and normalization

## Phase 2: Matching engine

- user profile model
- skill tagging
- location and type filtering
- ranking logic
- saved results

## Phase 3: Product interface

- web dashboard
- user auth
- favorites and notifications
- update frequency

## Phase 4: Scale and monetization

- more sources
- premium tier
- alert subscriptions
- B2B or career platform integrations

## Suggested quarter plan

### Q1

- research sources
- MVP schema
- first scraping adapters
- first test data

### Q2

- matching engine
- dashboard
- alerts and user flows

### Q3

- product polish
- pilot users
- UX improvements

## Success metrics

- % of jobs deduplicated correctly
- match accuracy for user profile
- user retention in first 30 days
- alert CTR
- time-to-first-relevant-job
